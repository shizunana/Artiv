# 绘约（HuiYue）项目开发计划书

> 版本：v1.0 ｜ 日期：2026-08-11 ｜ 项目定位：毕业设计

## 1. 项目概述

绘约是一个面向企划方与自由画师的美术约稿交易平台。核心业务闭环：

**发布需求 → 画师应征 → 选定下单 → 沟通修改 → 分阶段验收 → 互相评价**

系统分为三个部分：

- 前端：Vue 3 + Vite + Vue Router + Pinia（运行于 VS Code）
- 后端：Spring Boot 3 + MyBatis-Plus + JWT + WebSocket（运行于 IntelliJ IDEA）
- 数据库：MySQL 8.0（使用 Workbench / Navicat 管理）

## 4. 功能模块

### 4.1 用户模块

- 注册 / 登录（JWT 签发与校验）
- 用户资料维护（头像、昵称、简介、标签）
- 角色：企划方、画师、管理员

### 4.2 企划模块

- 发布企划（需求描述、预算、截止时间、参考图）
- 企划列表 / 详情 / 搜索
- 画师应征（附作品与报价）

### 4.3 订单模块

- 企划方选定画师并下单
- 分阶段验收（初稿、修改、终稿、交付）
- 订单状态流转（待接单、进行中、待验收、已完成、已取消）

### 4.4 消息模块

- 站内信（系统通知）
- WebSocket 实时推送（应征通知、验收结果、新消息提醒）

### 4.5 管理后台

- 用户管理（封禁 / 解封）
- 企划与订单审核、违规处理
- 数据统计（注册量、订单量、成交额）

## 5. 数据库规划

- 数据库名：`huiyue`，字符集 `utf8mb4`，引擎 InnoDB
- 表名 / 字段名：小写 + 下划线（如 `order_stage`）
- 主键：`id BIGINT AUTO_INCREMENT`；必备字段：`created_at`、`updated_at`
- 状态字段用 `TINYINT` + 后端枚举，不直接存中文
- ER 图见 [ER图.png](ER图.png)，建表脚本见 [../backend/sql/init.sql](../backend/sql/init.sql)

## 6. 开发规范

### 6.1 后端

- 接口前缀统一 `/api/v1`
- 返回结构统一 `{ code, message, data }`
- 异常统一抛给全局异常处理器
- 涉及金额、状态、他人资源的接口必须做登录与归属校验
- 包结构：`controller / service / mapper / entity / dto / vo / common / security / websocket`

### 6.2 前端

- 组件文件 PascalCase（`ProjectCard.vue`），路由 kebab-case（`/projects/new`）
- 页面放 `src/views/`，通用组件放 `src/components/common/`
- API 统一封装在 `src/api/`
- Prettier 自动格式化 + ESLint 校验

### 6.3 Git

- 分支：`main`（稳定版）、`dev`（日常开发）、`feature/xxx`（功能分支）
- 提交信息：`feat:` / `fix:` / `docs:` 前缀
- `.gitignore` 必须包含 `node_modules/`、`target/`、`uploads/`、`.idea/`、`.env.local`、`application-local.yml`
