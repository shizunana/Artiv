# 平台功能使用教程

核对日期：2026-09-10。依据当前工作区的页面、路由和关键服务校验编写，不以旧开发计划代替实际功能。

这是一套面向用户操作问题的通用教程，共 61 个独立主题，按八个模块分册。每个主题包含操作者/入口、操作步骤、结果及限制，可按主题编号单独提供给艺绘向导。

教程已通过向导只读工具接入：按关键词检索或按主题读取，单次最多三篇。管理员操作和向导测试教程由后端核验管理员身份后提供，普通教程与维护资料分开。没有修改现有教程页面或交易、删除规则；实现边界见[向导维护索引](维护索引.md)。

## 保留的现成教程

- 发布企划及企划方合作全流程：站内 `/guides/employer`，对应现有“企划方指南”。本套 PROJECT-01 引用它，不修改、不替换该页面。
- 画师认证准备与申请：站内 `/guides/painter-certification`，对应现有“画师认证指南”。本套 ACCOUNT-06 引用它，不修改、不替换该页面。

站内路径以当前部署域名为起点，不绑定某台电脑的 localhost。文档中的“订单详情”“目标主页”等动态页面，需先由用户列表或真实查询结果确定对象，不能编造 ID。

## 阅读约定

- 普通账号可读取 01～07 的 50 个主题；08 的 11 个主题仅正常管理员可读取。
- 标注“需要认证”指审核通过，不是注册时选择画师；工作台身份和认证状态分开判断。
- 所有提交、删除、扣款、验收、仲裁都以页面最终提示和服务端校验为准；教程不是额外授权。
- 没有实现的入口不写成可以使用：真实充值提现、任意源文件交付、部分退款、任意已完成订单继续退款、向导自动执行业务均不承诺。
- 教程描述如何操作，不证明已通过全链路安全或并发验收；已知技术风险仍在项目审查和未解决问题文档中维护。
