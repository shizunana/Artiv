# 艺绘向导使用教程

核对日期：2026-10-04。当前适用对象：正常状态的登录账号（企划方、画师及管理员），且向导服务已启用；不要求画师认证。

## GUIDE-01 打开、收起与保留聊天

入口：登录后页面右下角“艺绘向导”。登录、注册页不显示入口。

1. 点击入口展开右侧独立窗口。
2. 保持窗口展开时，仍可点击原页面、滚动页面或切换站内路由；点击窗口外不会自动关闭。
3. 使用窗口关闭按钮收起；收起不是“清空”，重新打开可继续会话。
4. 刷新后如果会话仍有效，打开会定位到最新消息；历史不是永久存档，重要内容请及时复制。

结果：页面浏览与聊天并存。退出/切换账号会清理当前账号状态，后端重启会清空临时会话。入口不见时先确认账号正常且仍登录，再刷新；服务配置问题应交给维护人员，不需要把密钥发到会话里。

## GUIDE-02 用角色图和参考图整理需求说明

入口：向导消息输入区及参考图上传按钮。

1. 选择自己的角色图，也可一起选择动作、服装等参考图；一次最多四张，当前支持 PNG/JPG，每张不超过 5 MB，会话内最多十二张。
2. 同时输入说明，例如：“图 1 是我的 OC，保留发色和服装；图 2 只参考动作。我想约一张头像，先帮我确认需求。”
3. 等待向导观察和追问，明确哪些内容要保留、哪些只供参考，以及用途、构图、预算或交付要求。
4. 有误直接在会话中纠正。确认后要求“整理成一份约稿需求说明”，再点击“复制需求说明”或“复制回复”。
5. 到发布企划表单自行填写并核对，不把模型总结视为已经发布成功。

结果：得到可继续修改的文字需求。参考图会发送给当前模型服务分析，上传前确认自己有权使用；不要上传证件、账号密钥等无关敏感材料。没有说明的设定由用户确认，不应把模型推测自动当成真实角色设定。

## GUIDE-03 查找企划、橱窗和画师

入口：向导聊天。

1. 说清要找的是企划、橱窗还是画师，并提供类型、题材、预算等条件。例如“找日系头像企划”“找可以购买的头像橱窗”“推荐几位擅长古风的认证画师”。
2. 等待真实查询结果，查看返回卡片中的标题、价格/预算、类型、题材及封面/头像。
3. 点击卡片进入当前详情，仍可继续点击其他卡片；报价、库存和可见性以当前详情为准。
4. 结果不足时可说“看看下一页”，或明确放宽题材等条件；多类型找画师也可要求“每个类型各推荐一位”。

结果与边界：公开企划需当前可招募；橱窗需上架且有库存。找画师按三个依据：认证且账号正常、类型匹配公开作品或在售有库存橱窗、题材匹配画师个人标签。未填标签的画师可在不限题材时出现，不能被推断为擅长所有题材。同一画师可匹配多类并合并为一张卡片；本页候选数不是全平台总人数。画师没有统一报价，具体价格和交期以橱窗或沟通为准。

卡片封面、头像用于展示，不代表向导已经分析过推荐作品图片。资源变为不可见时，旧卡片可能无法继续打开，应重新查询而不是绕过访问限制。

## GUIDE-04 询问规则或本人业务状态

入口：向导聊天。适用范围：已开放的规则查询，以及当前账号本人可见的企划、订单、邀请只读查询。

1. 提出具体问题，例如“接受邀请之后还需要下单吗”“这个订单下一步该谁操作”。
2. 涉及具体记录时说明是哪一笔；信息不清时先确认对象，不猜测其他人的私有数据。
3. 根据回复去相应页面查看实际按钮，由你本人完成操作。

结果：向导帮助理解，不代为发布、发邀请、下单、付款、交稿、验收或修改余额。规则回复不展示内部手册路径；公开资源仍应保留详情卡片跳转。

使用功能有疑问时，可直接问“如何发布企划”“橱窗怎么修改”等，向导会查询相应使用教程。它不会替你执行步骤；回答仍需结合当前页面和业务状态确认。

## GUIDE-05 停止生成、复制与清空会话

入口：向导窗口的生成状态按钮、回复下方复制按钮、顶部“清空”。

1. 回答不再需要时点击“停止生成”；被停止的回答可能不完整。
2. 需要保存时使用回复的复制按钮；复制失败可手动选中文字。
3. 要彻底重新开始，点击“清空”，核对提示再确认。

结果：停止不代表清空；收起也不代表清空。确认清空会移除聊天和参考图，正在生成的内容也会停止，无法从界面恢复。重要需求先复制保存。
