# 使用教程维护与向导接入索引

核对日期：2026-09-10。本文仅供项目维护者，不属于给普通用户展示的教程正文，也不应作为向导回复里的“查询依据”显示。

## 1. 当前产物与加载状态

- 八份教程、61 个主题，以 `## ACCOUNT-01 …` 等二级标题为切分单位；同一主题包含入口、受众、步骤和边界，不将限制段落从操作步骤中拆走。
- 不重做已有 `EmployerGuide.vue`、`PainterCertificationGuide.vue` 页面；保留它们的真实站内入口。
- `GuideTutorialBook` 从 classpath 读取八份白名单教程，Maven 构建时从本目录打包到 `guide/tutorials`。README、维护索引及其他文档不打包，不运行时扫描仓库目录；可随 JAR 部署，不依赖本机绝对路径。
- `read_artiv` 新增 `tutorials` 操作：无参数列当前可读主题目录；`keyword` 检索返回最多三篇全文；`topicIds` 精确读最多三篇，二者互斥。检索使用标题优先的中文双字匹配，不接外部向量库；无匹配可查目录再读正文。
- 管理员与向导测试主题共 16 篇，由数据库账号的角色、正常状态及未删除标记核验后才进入目录、检索或正文；普通主题 45 篇。管理员会话总入口仍维持管理员测试范围，未向普通账号开放向导。
- 教程返回不生成 references，不进入浏览器的引用事件或会话引用存储。模型收到的内容不含源文件路径；维护索引永不作为教程发送。原企划、橱窗、画师推荐卡片及复验逻辑保留。
- `GuideRuleBook` 原规则单独保留，没有把 61 篇塞进最多 30 条的规则库。提示词要求如何使用先查教程，具体记录状态仍查本人数据；明显使用问题在回答执行器中要求实际教程读取，避免凭目录或模型记忆回答。
- 教程修改后需要重新构建/运行后端以打包并重新加载；不是热更新。前端页面、HTTP 接口和数据库未修改，更新的是后端内部工具与提示词。

## 2. 主题字段与扩展约定

当前返回字段为 `topicId/title/audience/body`；目录不含 body。下表其他字段是维护约定或后续扩展，并非已返回的接口字段。具体前提和站内入口保留在正文中。

| 字段 | 内容 |
| --- | --- |
| topicId | 固定主题编号，例如 `PROJECT-08`；修改内容不随意更名 |
| title | 面向用户的功能标题 |
| audience | 访客、普通登录用户、企划发布者、认证画师、订单双方、管理员等真实受众 |
| keywords | 用户常用问法，如“删除邀请、隐藏邀请、拒绝邀请” |
| entryRoutes | 从真实路由校验的静态入口；动态目标必须由用户可见记录解析 |
| prerequisites | 登录、身份、认证、资源归属、状态限制 |
| body | 步骤、结果、限制和容易混淆的行为 |
| verifiedAt | 核对日期，当前为 2026-09-10 |
| internalSources | 本文下面的代码核对位置，只供维护，不进入普通用户回答 |

先按问题和受众选择少数主题，再结合实时业务状态回答。不能把整套开发文档、测试账号、部署配置、密钥或私有记录一并送进上下文。管理员教程与普通教程已做服务端权限隔离；聊天中自称管理员不算身份验证。

## 3. 回答呈现约定

1. 用户问“怎么用”时，先说去哪里，再给必要的三到五步；有关键条件必须一起说。
2. 已有指南优先提供 `/guides/employer` 或 `/guides/painter-certification`，不要暴露源文件路径。
3. 用户问具体状态时先读取本人有权访问的记录；一般教程不能证明某笔订单现在可以取消或某个企划现在可以删除。
4. 规则、教程不显示 Markdown 文件名、后端目录、内部索引、源码链接或“来源：某文件”。真正的公开企划、橱窗、画师仍保留现有可见性复验与可点击资源卡片。
5. 页面导航入口与业务资源卡片是两类信息。新建教程跳转能力时需限定合法站内路由，不让模型自由构造任意链接，不伪造未查询到的资源 ID。
6. 限制或事实不清楚时如实说明，不猜测不存在的按钮、人工承诺或支付能力。保留当前纯文本回复风格，不要求用户阅读格式标记。

## 5. 本轮纠正的容易误写之处

- 余额实际在顶部头像菜单，不在普通工作台概况卡片中；充值/提现是提示“开发中”的占位按钮。
- 橱窗详情修改仅库存与追加题材，不能按旧功能概览概括成“任意编辑橱窗”。
- 被拒绝的定向企划通过面板上架开关转公开，不虚构另一个“转公开”按钮。
- 发布企划的合作方式位于需求详情阶段，预览阶段负责核对；与真实页面一致。
- 当前交付组件只支持图片，稿件要求里可选的 PSD 等格式不代表交付上传器已经支持对应源文件。
- 订单页面的争议入口只在进行中或待验收出现；不能因旧概述用了“售后”一词，就许诺所有已完成订单都有退款入口。
- 每方一次争议图片证据、每方一次限时评价，不能写成随时无限补充。
- 企划任意关联订单禁止删除，与橱窗仅未完成订单禁止删除的口径分开；提醒隐藏不会终结邀请。
