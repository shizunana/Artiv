# 作品与橱窗管理使用教程

核对日期：2026-09-10。作品用于展示创作；橱窗用于出售明确的服务，两者不是同一种发布。

## WORK-01 上传作品

适用对象：普通用户，可先上传作品准备认证。入口：画师工作台 → 我的作品 `/painter/works`。

1. 点击“+ 上传作品”，填写作品标题，最长 20 字。
2. 选择类型和至少一个题材风格；作品仍使用原十类和原题材选项，不使用企划的六类。
3. 选择“公开”或“仅自己可见”，可填写不超过 500 字的作品说明。
4. 上传一张作品图，等待成功后点击“保存”。当前选择器支持 PNG、JPG、GIF、WEBP。

结果：作品出现在“我的作品”；公开作品可进入广场，私密作品只供自己管理。一个作品条目只保存一张作品图；上传本人的创作，不要将他人参考图冒充认证作品。未完成必填项时无法保存。

## WORK-02 隐藏作品或重新公开

适用对象：作品作者。入口：我的作品 → 目标卡片。

1. 找到作品，核对标题和图片。
2. 公开作品点击“隐藏”；需要再次展示时对隐藏作品使用“公开”。
3. 检查卡片可见性状态是否更新。

结果：隐藏后退出作品广场等公开展示，但本人仍可管理；重新公开不需要再次上传。隐藏与删除不同。准备认证时，请保证满足要求的作品实际处于公开状态。

## WORK-03 单件与批量删除作品

适用对象：作品作者。入口：我的作品 → 卡片“删除”，或顶部“删除作品”。

1. 单件删除时使用目标卡片按钮；批量时打开顶部选择窗口。
2. 勾选要删除的作品，翻页时核对已选择项及数量，不把“全选”理解为自动删除库中全部作品。
3. 在确认提示中核对目标后提交。

结果：本人公开或隐藏的作品均可删除；删除后不再公开展示，用户页面没有恢复入口。批量操作逐项遵守已有删除校验，遇到失败先检查剩余记录和提示，不假定整批全部成功。

## SHOP-01 创建橱窗服务

适用对象：认证画师。入口：我的橱窗 `/painter/stalls` → “+ 创建橱窗”。

1. 填写服务名称、原十类中的类型，准备封面和详情图；详情图至少一张、最多九张。
2. 填写价格、库存、截稿时间说明，例如从确认接单开始计算的交付周期。
3. 设置创作阶段名称和顺序，填写颜色模式、尺寸规格、交付格式、题材风格。
4. 填写服务描述，说明成稿内容、修改约定、可接/不接范围，最长 500 字。
5. 点击“保存”，在我的橱窗及详情中检查上架状态、图片和参数。

结果：建立服务条目。有库存且上架才可被购买。未认证时应先完成认证；保存前仔细核对交易信息，创建后不能随意整体重写。

## SHOP-02 修改库存与追加题材

适用对象：橱窗所属画师。入口：我的橱窗 → 编辑，或自己的橱窗详情 → 修改橱窗。

1. 打开修改窗口，输入新的剩余库存。
2. 如需扩充题材，在题材风格中追加选项。
3. 点击“保存修改”，查看新的库存与题材。

结果：库存可调整，库存为零时退出可售大厅；已有题材不可删除，只能追加。当前不是完整橱窗编辑器，不能从这个窗口改价格、服务名、封面、描述或创作阶段。不要教用户通过修改旧服务来改变已成立交易。

## SHOP-03 上下架橱窗

适用对象：橱窗所属画师。入口：自己的橱窗详情 → 修改橱窗。

1. 暂停承接新单时点击“下架橱窗”。
2. 重新承接时检查库存，再点击“上架橱窗”。
3. 核对状态；库存仍为零时，仅上架也不会恢复可购买状态。

结果：上下架控制新购买，不取消已经成立的订单。临时停止接稿优先使用下架，已有订单仍要在订单页面完成履约。

## SHOP-04 删除橱窗

适用对象：橱窗所属画师。入口：我的橱窗 → 删除橱窗，或详情修改窗口的删除入口。

1. 查看目标是否可选；灰色表示存在未完成订单，当前不能删除。
2. 勾选允许删除的目标，核对标题和数量后确认。
3. 删除后检查剩余列表。

结果：删除同时下架且不能从用户页面恢复。与企划不同，橱窗是“存在未完成订单”时禁止删除，不是有任何历史订单都禁止；已完成或已取消订单保留历史记录。不能靠下架绕过未完成订单保护。

## SHOP-05 购买橱窗

适用对象：登录的购买方，使用企划方身份；不能购买自己的服务。入口：他人的可售橱窗详情。

1. 阅读服务说明、作品图、固定价格、库存、交付周期和创作阶段。
2. 点击“立即下单”，在确认窗口再次核对画师、服务与金额。
3. 点击“确认下单”，等待返回结果；之后进入“我委托的订单”。
4. 在自动建立/复用的会话中向画师补充需求，等待画师确认接单。

结果：托管固定金额、扣减一件库存并建立待接单订单。余额不足、售罄、已下架或双方屏蔽会阻止购买。待接单时可按订单入口取消；超时或网络错误后先查看订单与余额，不要连续重复确认。
