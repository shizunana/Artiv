# 订单、交付与评价使用教程

核对日期：2026-09-10。适用于订单双方。企划订单与橱窗订单入口不同，成立后复用同一套履约界面。平台资金为模拟余额，不是实际支付、充值或提现服务。

2026-09-11 补充：企划订单用途快照。

## ORDER-01 查找订单、查看快照和记录

入口：企划方“我委托的订单” `/dashboard/orders`；画师“我承接的订单” `/painter/orders`。

1. 切换到自己在该笔订单中的身份，进入对应列表。
2. 使用“全部订单”“待交付”“待评价”“退款/售后”等页签定位目标。
3. 打开订单详情，核对订单编号、对方、金额、状态和创作阶段。
4. 查看来源摘要、企划快照（企划订单）及“订单记录”；联系对方使用订单中的联系按钮。

企划下单快照显示下单时的个人/商业用途，不随来源企划后来修改而变化。旧订单没有记录时显示“未记录用途”，不代表个人用途。用途不改变报价或交易操作；橱窗订单不套用这一企划字段。

结果：看到订单真实进展，不要仅凭来源企划的招募状态判断交易状态。企划和橱窗订单有各自的来源快照，不能认为两类快照包含完全相同字段。来源被下架或删除不等于订单消失。

## ORDER-02 确认接单、拒绝接单与取消订单

适用状态：待接单。入口：该笔订单详情。

1. 画师核对金额、需求和创作阶段，愿意合作点击“确认接单”。
2. 不接受时由画师点击“拒绝接单”，按弹窗填写原因并确认。
3. 画师接单前，企划方也可点击“取消订单”，说明原因并确认。
4. 查看更新后的状态及订单记录，避免重复操作。

结果：接单后进入创作阶段；取消/拒接按规则退还托管金额，橱窗订单按规则恢复库存。已接单不能继续使用待接单取消入口；进行中或待验收的分歧按 ORDER-06 处理。

## ORDER-03 画师提交当前阶段

适用对象：承接画师；订单进行中。入口：订单详情 → 交付当前阶段。

1. 对照当前阶段和最近修改意见准备图片。
2. 点击“交付当前阶段”，填写交稿说明，上传 1–9 张交付图片。
3. 等待所有图片上传完成，再点击“提交交稿”。
4. 在详情确认进入待验收，等待企划方操作。

结果：记录当前阶段的新版本并提供预览。当前交付入口是图片上传，不能因为需求里写了 PSD、AI 等格式，就认为此处已经支持任意源文件上传。非图片交付先与对方确认安排，不要承诺平台存在未实现的附件入口。被要求修改后，重新提交当前阶段，不要误当作进入下一阶段。

## ORDER-04 企划方验收或要求修改

适用对象：委托企划方；订单待验收。入口：订单详情 → 创作阶段。

1. 查看当前交付图片、说明和阶段名称。
2. 需要修改时点击“要求修改”，写清位置、问题和期望效果；画师修改后重新交付。
3. 当前阶段通过且还要继续创作时，点击“通过并进入下一阶段”。
4. 全部需求已经满足时，点击“确认当前交付并完成交易”。最后阶段也通过这个完成入口结束交易。

结果：通过阶段继续履约；要求修改回到当前阶段创作；完成交易会结算托管金额，不能把它当作普通“我看到了”确认。提前完成会跳过后续阶段，操作前确认确实不再需要后续交付。

## ORDER-05 获取完成后的原图

适用对象：订单双方，重点为委托企划方。入口：已完成订单详情的当前交付区域。

1. 确认订单已完成，再打开订单详情。
2. 在交付区域查看当前版本原图链接，逐张打开/保存需要的图片。
3. 对照约定核对尺寸、版本与数量；页面没有提供的文件格式需与画师确认。

结果：企划方在正常订单页面中，完成前查看水印预览，完成后获取当前版本原图。不要承诺这里提供所有历史版本的打包下载，也不要把页面展示规则描述成已经验证的绝对文件保密保障。

## ORDER-06 发起争议与补充证据

适用对象：订单双方；订单进行中或待验收。入口：订单详情 → 申请争议仲裁。

1. 先通过站内会话沟通，无法解决时点击“申请争议仲裁”。
2. 填写争议原因，可附图片证据和说明，核对后提交。
3. 进入争议状态后阅读详情；尚未提交图片证据的一方可用“补充图片证据”，一次上传至少一张、最多九张。
4. 等待管理员仲裁，在订单和系统消息中查看结果。

结果：订单暂停普通履约操作，等待仲裁。每一方只能提交一次图片证据，申请时已经附图也计入这次机会，先整理完整再提交。已处理争议不能继续补证。当前支持全额退款企划方或全额结算画师，不支持部分退款；已完成订单没有本界面的继续争议入口，不要承诺完成后任意发起退款。

## ORDER-07 完成后评价合作

适用对象：已完成订单双方。入口：订单详情“去评价”，或订单列表“待评价”。

1. 在完成后的 7×24 小时内打开评价入口。
2. 选择 1–5 星，可填写不超过 500 字评价，附最多六张图片。
3. 检查内容并点击“提交评价”。
4. 查看订单评价状态及对方对应身份的公开合作评价。

结果：双方各有一次评价机会，逾期不自动好评。不要承诺可以反复修改或补评。画师和企划方的评价按合作身份分别展示，不混成一份身份评分。

## ORDER-08 画师申请删除不当评价

适用对象：收到评价、且页面允许申诉的画师。入口：自己的画师主页 → 合作评价。

1. 找到目标评价，点击“申请删除评价”。
2. 填写具体申诉原因，确认提交。
3. 在评价旁查看申诉审核状态，等待管理员结论。

结果：提交申请不会立即删除评价；管理员批准后隐藏且不再计入公开评分，驳回则保留。该功能不是任意用户删除他人评价的权限，也不让画师直接改动星级和文字。
