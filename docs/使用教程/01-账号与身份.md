# 账号与身份使用教程

核对日期：2026-09-10。适用于普通账号；管理员使用独立后台。本文只介绍现有功能。

## ACCOUNT-01 注册、登录与退出

适用对象：访客、普通用户。入口：登录页 `/login`、注册页 `/register`、顶部头像菜单。

1. 首次使用时打开注册页，填写用户名、昵称、密码，选择初始身份。
2. 用户名按页面要求填写 3–20 位字符，密码为 6–32 位；昵称用于对外展示，不能与已有昵称重复。
3. 点击“注册”，完成后按页面提示登录。登录使用用户名和密码，不是画师笔名。
4. 要退出账号，使用顶部头像菜单的退出入口；更换账号前先退出。

结果：登录后可以进入对应工作台。注册选择画师不等于通过画师认证；账号被封禁、凭据错误或登录失效时按页面提示处理。当前没有自助“忘记密码”找回流程，不要寻找短信找回、自动注册管理员等不存在的入口。

## ACCOUNT-02 切换企划方与画师工作台

适用对象：普通登录用户。入口：工作台左侧底部“切换到画师工作台”或“切换到企划方工作台”。

1. 进入当前工作台，查看左上角的当前身份。
2. 点击侧栏底部的切换按钮，等待进入另一套菜单。
3. 发布企划、管理委托订单使用企划方工作台；管理作品、橱窗、应征、邀请和承接订单使用画师工作台。

结果：同一账号切换使用场景，不会创建新账号，也不会清空资料、收藏或订单。无需认证即可先切换到画师工作台准备作品；应征、接受邀请、创建橱窗仍需要认证。公开主页上的“切换身份”只改变所看主页的身份视角，不等于切换自己的工作台。管理员不通过此按钮变成普通交易账号。

## ACCOUNT-03 修改头像与基础资料

适用对象：普通登录用户。入口：顶部头像菜单 → 账户设置 `/settings`。

1. 在账户设置的个人头像区域选择新头像，完成页面提供的上传操作。
2. 在“基础资料”修改昵称、企划方个人简介等可编辑字段。
3. 点击“保存基础资料”，确认成功提示，再查看自己的企划方主页。

结果：昵称、头像用于平台展示，企划方简介只展示在企划方视角。用户名不是昵称，不要把只读字段当作改名入口；画师简介在“身份认证 · 画师信息”中单独维护。

## ACCOUNT-04 修改登录密码

适用对象：普通登录用户。入口：账户设置 → 修改密码。

1. 输入当前密码。
2. 输入 6–32 位新密码，并再次输入确认。
3. 点击“更新密码”。如果后续提示重新登录，使用新密码登录。

结果：密码更新。当前密码错误或两次新密码不一致时不会完成修改。不要把密码、API Key 或验证码发给向导；向导不能代替你修改密码。

## ACCOUNT-05 完善画师简介与题材风格

适用对象：准备认证或已认证的普通用户。入口：账户设置 → 身份认证，`/settings?section=identity`。

1. 找到“画师公开资料”，填写自己的创作方向、合作偏好等简介。
2. 在“题材风格”选择实际擅长的标签，可多选。
3. 点击“保存画师资料”，进入自己的画师主页核对。

结果：公开资料立即更新，不触发认证复审。向导按题材找画师时使用这里的个人标签；不填写标签不会阻止不限题材查询，但无法命中指定题材的筛选。标签不是画师认证，也不是价格或接稿档期承诺。

## ACCOUNT-06 申请画师认证（引用现有指南）

适用对象：尚未认证的普通用户。现成教程：站内“画师认证指南” `/guides/painter-certification`。操作入口：账户设置 → 身份认证。

1. 先阅读现有指南，完善画师简介，准备至少 4 件公开作品及本人常用创作主页。
2. 在身份认证区域点击“前往申请”，查看条件是否满足。
3. 按现有申请表填写画师笔名、常用站，检查后点击“提交认证”。
4. 等待系统消息中的审核结果。被驳回时根据原因修正后再申请；审核中不要重复提交。

结果：审核通过后开放需要认证的接稿功能。认证教程页面保持原样，本节只提供入口和操作导航，不另建一份替代指南。私密或已删除作品不应被当作满足公开作品数量的材料。

## ACCOUNT-07 修改已认证信息

适用对象：已认证画师。入口：账户设置 → 身份认证 → 修改认证信息。

1. 点击“修改认证信息”，填写新笔名和新常用站。
2. 点击“提交修改审核”，等待管理员处理。
3. 通过系统消息和认证区域查看审核结果。

结果：新资料通过前继续使用原正式认证资料；有待审核的修改申请时不能重复提交。只改简介或题材标签请使用 ACCOUNT-05，不必走认证资料复审。

## ACCOUNT-08 查看自己的业务概况与余额

适用对象：普通登录用户。入口：企划方工作台 `/dashboard` 或画师工作台 `/painter`。

1. 打开工作台首页，查看当前身份的业务概况及待处理提示；新账号可能先显示首次使用引导。
2. 要处理具体记录，进入“我的企划”“收到的邀请”或对应订单列表，不只依赖概况数字。
3. 要看另一身份的数据，先切换工作台。查看余额请打开顶部头像菜单，在“资金管理 → 账户余额”查看，不在工作台概况中寻找余额卡片。

结果：找到当前需要处理的业务。平台使用模拟余额；菜单虽有“充值”“提现”按钮，目前点击只提示“资金管理功能正在开发中”，没有真实充值、提现流程。测试余额不足时联系测试管理员，不要向向导提供银行卡或要求它自行加余额。
