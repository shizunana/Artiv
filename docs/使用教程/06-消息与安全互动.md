# 消息与安全互动使用教程

核对日期：2026-09-10。适用于普通登录用户。举报、屏蔽、退款、删除评价是不同功能，不能相互替代。

## MESSAGE-01 找到合作会话、发送文字

入口：顶部“消息” → `/messages` → 我的消息；也可从企划应征管理或订单联系入口进入。

1. 在左侧会话列表选择合作对象。普通应征通常由企划方发起沟通；接受邀请或购买橱窗后会建立/复用双方会话。
2. 在输入框填写文字，点击“发送”或按 Enter；Shift + Enter 换行，单条最多 500 字。
3. 打开会话查看最新消息，需要查看旧内容时向上滚动。
4. 需求变化、验收标准等重要约定尽量在会话中说明，涉及多笔业务时注明标题或订单编号。

结果：同一对用户共用一条会话，不会为每个企划各创建一个独立联系人。会话存在不等于已接单；正式状态看订单。屏蔽关系会阻止普通私信，但历史会话仍保留。

## MESSAGE-02 发送图片与订单卡片

入口：消息中心 → 目标会话 → 输入区扩展按钮。

1. 使用图片按钮选择图片，单次最多九张、每张不超过 5 MB。
2. 检查待发送预览，移除选错的图片，点击“发送 N 张图片”。仅选图不等于已发出。
3. 需要指明某笔交易时使用订单卡片入口，按页面提供的关联订单选择/发送。
4. 对方可点击业务卡片查看其有权访问的详情。

结果：图片和卡片发送到当前会话。不要把向导的四图限制套在私信上；也不要用卡片发送替代正式下单、交稿或验收。没有可用关联订单时不能凭空创建订单卡片。

## MESSAGE-03 查看系统通知与标记已读

入口：消息中心 → 系统消息。

1. 查看应征、邀请、订单、认证及治理等业务通知。
2. 使用通知提供的详情操作进入对应企划或订单，再完成实际业务操作。
3. 已看完的通知可以用“全部已读”消除未读提醒。

结果：已读只改变提醒状态，不接受邀请、不接单、不确认交付。旧通知描述的是发生时的事件，资源后续删除或状态变化后，以当前详情为准；并不是所有治理操作都向举报人发结果通知。

## SAFETY-01 屏蔽用户与解除屏蔽

入口：他人公开主页的更多操作 → 加入黑名单；管理入口：账户设置 → 黑名单管理。

1. 在对方主页打开更多菜单，选择“加入黑名单”，阅读影响并确认。
2. 如果提示存在未完成订单，先通过订单流程处理，不能靠屏蔽绕过履约。
3. 要解除时，在主页选择“解除黑名单”，或在黑名单管理列表中点击“解除屏蔽”。

结果：按整个账号限制双方关注、邀请、应征、下单、建立会话和普通私信；待处理邀请会失效，尚未下单的应征关系会结束。公开内容和历史记录不会因此全部消失。解除屏蔽不自动恢复已经失效的邀请或应征；若对方仍屏蔽你，互动仍可能受限。

## SAFETY-02 举报用户

入口：他人公开主页 → 更多操作 → 举报用户。

1. 核对举报对象，选择举报类型。
2. 填写 10–500 字说明，描述具体事件，可上传最多六张证据图片。
3. 点击“提交举报”，确认提交提示；同一举报人重复举报不重复计数。

结果：提交给管理员处理，不会自动屏蔽、封禁或退款；当前也不会向举报人推送处理结果。需要停止互动使用黑名单；订单资金争议使用“申请争议仲裁”；画师对自己收到的评价申诉使用“申请删除评价”。
