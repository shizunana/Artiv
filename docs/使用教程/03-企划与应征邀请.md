# 企划、应征与邀请使用教程

核对日期：2026-09-11（补充稿件用途）。每节标注实际操作者；接受邀请和正式下单是两个不同操作。

## PROJECT-01 发布企划（引用现有指南）

适用对象：企划方工作台的普通用户。入口：发布企划 `/dashboard/projects/new`。现成教程：企划方指南 `/guides/employer`。

1. 先阅读现有企划方指南，准备需求、预算、参考图及目标合作方式。
2. 第一阶段“稿件用途”：单选六类企划类型之一，选择个人/商业用途，填写稿酬预算和截稿日期。
3. “需求详情”：填写标题、需求、参考图及页面要求的稿件信息，按需要调整创作阶段；在合作方式中选择公开招募或定向邀请，定向邀请须选择唯一认证画师。参考图最多六张，第一张作为封面。
4. “高级选项”：选择适用于当前类型的题材按钮、稿件格式及公开权限。题材默认“不限”，选具体项会取消不限，点“不限”会清空具体项。
5. 在“预览企划”核对内容及公开/定向发布设置，使用页面发布按钮完成。

结果：公开企划供画师应征；定向企划只面向指定画师，不进公开大厅。提交前更换企划类型时，检查题材是否有不再适用而被移除的项目。

稿件用途：选择个人用途或商业用途，保存后在大厅卡片和企划详情“稿件要求”显示。大厅暂不支持用途筛选。这项选择不自动改变报价、付款或合作方式，也不是画师公开作品的权限开关。订单建立时会独立保存当时用途供双方查看。

注意：这里的截稿日期至少为操作当天两天后，控制招募期限，不是订单强制交付截止时间。实际合作交期需另行确认。现成指南页面不改动，本节只补充当前入口与表单导航。

## PROJECT-02 找到自己的企划与管理面板

适用对象：企划发布者。入口：我的企划 `/dashboard/projects`。

1. 根据发布方式选择“公开企划”或“定向邀请”页签。
2. 在目标卡片点击“企划详情”查看内容；点击“企划面板”管理该企划。
3. 面板集中查看应征/邀请画师、招募状态、可用的编辑操作和参与画师订单。
4. 查某笔交易的进度时打开对应订单，不以应征状态代替订单状态。

结果：进入自己的管理范围。当前“企划面板”会打开新标签页；弹出被浏览器拦截时检查浏览器提示。其他用户不能管理你的企划。参与画师区域保留真实订单历史，不只是正在合作的人。

## PROJECT-03 编辑企划内容、修改日期与上下架

适用对象：企划发布者。入口：目标企划面板。

1. 修改标题、需求、图片、预算、个人/商业用途等完整内容时，点击“编辑企划”，修改并保存；已有有效应征、有效邀请或历史订单时不能完整编辑。
2. 只调整招募日期时，使用标题区域的日期修改入口，选有效日期并点击“保存截稿日期”。
3. 暂停招募使用摘要区域的上下架开关；重新上架按提示提供有效日期。
4. 保存后分别核对面板和公开详情。

结果与限制：已有有效应征、有效邀请或历史订单时，完整内容编辑会锁定；不能通过修改日期绕开完整内容保护。上下架、日期和删除是不同能力，不能因为某个按钮可用就认为其他操作也可用。管理员违规下架的企划不能靠发布者自行切换恢复。来源内容调整不会重写已经生成的订单快照。

## PROJECT-04 删除自己的企划

适用对象：企划发布者。入口：我的企划 → 删除企划。

1. 先切到目标所在的公开/定向页签，再打开“删除企划”。
2. 查看可选择记录及灰色记录的原因，勾选目标。
3. 核对标题和数量，确认删除。

结果：可删除企划同时退出公开展示，且不能从用户页面恢复。存在关联订单的企划不能删除，已完成或已取消的历史订单也属于关联订单；存在待回应定向邀请也会阻止删除。不要把“删除邀请提醒”当作解除企划删除限制的方法。若只想暂时停止招募，使用下架，不要删除。

## PROJECT-05 应征、修改报价与取消应征

适用对象：认证画师。入口：企划大厅 → 目标详情；后续入口：我的应征 `/painter/applications`。

1. 找到仍允许招募的公开企划，阅读内容后点击应征入口，填写说明和报价，点击“提交应征”。
2. 在“我的应征”找到目标，点击“更改应征”进入详情调整报价，保存修改。
3. 不想继续时，在应征操作弹窗点击“取消应征”并确认；如果已有业务关系阻止取消，按页面提示处理。
4. 等待企划方沟通或发单；正式订单到来后进入“我承接的订单”确认接单。

结果：应征建立合作候选关系，不会自动生成订单，也不代表已被选定。“我的应征”只展示当前有效关系；取消或合作结束后移出，不是完整历史档案。带价邀请产生的报价被锁定，页面可能显示“查看应征”，不能当普通报价自由修改。不能应征自己的企划；未认证、过期、下架或屏蔽关系均可能阻止操作。

## PROJECT-06 向公开企划主动邀请画师

适用对象：拥有招募中公开企划的企划方。入口：认证画师主页“邀请”，或自己的企划面板邀请区域。

1. 在画师主页点击“邀请”，选择本人仍可招募的公开企划；也可在面板通过关注画师或昵称搜索选择目标。
2. 选择“邀请报价”（让画师自行报价格）或“带价邀请”（你先给出价格）。
3. 带价邀请填写不低于 50 元的价格，可补充说明，再发送邀请。
4. 等待画师接受；接受后检查有效应征、沟通细节，再由企划方正式发单。

结果：接受后建立应征并建立/复用会话，不自动扣款下单。带价邀请按邀请价形成锁价应征。没有可选企划时先发布公开企划；已存在有效应征、企划失效或双方屏蔽时不能继续邀请。一个公开企划可以邀请不同画师。

## PROJECT-07 接受或拒绝收到的邀请

适用对象：被邀请的认证画师。入口：收到的邀请 `/painter/invitations`，或邀请通知关联的企划详情。

1. 用“待处理”等状态筛选找到邀请，打开企划阅读需求。
2. 接受定向邀请或邀请报价时填写报价；接受带价邀请时先核对已确定的邀请价格。
3. 点击接受并确认；不参与时选择拒绝，填写婉拒理由后确认。
4. 接受后到消息中心沟通，等企划方发送订单；收到订单后仍要单独确认接单。

结果：接受形成应征和会话；拒绝不建立会话。定向企划被拒绝后自动下架，公开企划的一次邀请被拒绝不等于整个公开企划下架。过期邀请不能再接受，已接受关系不会因为后来过期自动终止。

## PROJECT-08 删除邀请提醒

适用对象：收到邀请的画师。入口：收到的邀请 → 删除邀请。

1. 打开删除选择窗口，勾选不希望继续在提醒列表看到的邀请。
2. 核对目标后确认删除。
3. 想明确拒绝合作应另外使用“拒绝”操作，不要只删除提醒。

结果：只是隐藏本人的邀请提醒，不改变邀请的业务状态，不删除应征、消息、会话或订单。待处理提醒被隐藏也不代表画师已拒绝；所有后续业务仍按原有状态校验。

## PROJECT-09 被拒绝的定向企划改为公开招募

适用对象：该定向企划的发布者。入口：我的企划 → 定向邀请 → 目标企划面板。

1. 确认指定画师已拒绝，企划当前已下架。
2. 先设置有效截稿日期，再打开面板的上架开关；被拒绝的定向企划通过该开关转为公开企划。
3. 确认转换后，到公开企划页签和大厅检查结果。

结果：转为公开招募，不自动带入原拒绝画师作为应征。该入口不是随时撤回待回应邀请、换人邀请的功能；未满足状态条件时不要尝试通过删除提醒替代。

## PROJECT-10 从有效应征发送企划订单

适用对象：企划发布者。入口：目标企划面板的应征画师操作区域。

1. 对照作品、报价和说明选定画师，先发起沟通确认需求范围。
2. 使用发送订单操作，核对画师、企划及报价。
3. 在托管确认提示中点击确认发送，等待成功结果。
4. 在“我委托的订单”或面板参与画师区域查看新订单，等待画师接单。

结果：按当前有效应征报价创建待接单订单，并从模拟余额托管金额。邀请尚未接受、没有有效应征或余额不足时不能正常发单；同一企划同一画师已有未完成订单时不能重复发单。公开企划可分别向不同有效应征画师发单。网络超时后先查订单是否生成，再决定是否重试。
