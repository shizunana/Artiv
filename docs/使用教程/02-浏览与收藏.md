# 浏览与收藏使用教程

核对日期：2026-09-10。公开浏览面向访客与普通用户；关注、收藏及个人列表需要登录。

2026-09-11 补充：企划大厅卡片用途标签。

## BROWSE-01 在企划大厅找约稿需求

入口：顶部“企划” → `/projects`。

卡片原“公开招募”位置现在显示“个人用途”或“商业用途”，帮助判断需求用途；题材标签照常保留，暂时没有用途筛选项。点击详情可在“稿件要求”查看用途和单独的稿件公开约定。

1. 打开“类型与题材”，选择感兴趣的企划类型：头像、立绘、角色设计、插画、平面设计、自设/OC。
2. 类型可多选，多选表示任一所选类型的企划都可出现，不要求一个企划同时属于多个类型。
3. 只选一个类型时，下方才显示该类型适用的题材风格，可多选；不选类型或选多个类型时，题材隐藏并清空。
4. 点击“确定”才应用本次类型/题材选择。“重置”只清空面板待选项，仍要点击“确定”；没有点击确定就关闭，不改变已应用筛选。
5. 还可调整排序、稿酬区间、截稿日期、“仅看未选定”，或输入标题/需求关键词搜索，点击企划卡片查看详情。

结果：显示当前可公开招募且符合筛选的企划。类型、题材不选就是不限制，不需要找“不限”按钮。

例子：选“头像”，再选“Q版、日系”，会找到至少含这两个题材之一的头像企划，不是必须同时有两项。匹配企划还可以带“有背景”等其他标签；但只有“有背景”、完全不含任一所选标签的企划不应命中。企划自己没有填题材时，只在不限制题材的查询中保留，不会匹配任意具体标签。

没有结果时：先确认点击过“确定”，再逐步清除题材、预算、关键词和日期限制。定向企划、已下架、已删除或招募过期企划不会因为清空筛选重新变成公开招募。

## BROWSE-02 在橱窗大厅找服务

入口：顶部“橱窗” → `/stalls`。

1. 从分类栏选择服务类型，或保持“全部”。橱窗仍使用原有十类，不使用企划的六类。
2. 按需要选择题材风格、价格区间、截稿时间及排序；搜索服务名称后按回车。
3. 打开卡片，检查详情图、说明、价格、库存、交付时间、阶段和稿件参数，再决定是否购买。

结果：找到当前可售服务。列表的交付时间筛选不能代替与画师确认实际安排；售罄或下架服务不能新下单。这里的题材筛选不是企划大厅的多选面板。购买步骤见 SHOP-05。

## BROWSE-03 查找画师与查看公开主页

入口：顶部“画师” → `/artists`；点击画师卡片进入公开主页。

1. 在“推荐”中浏览认证画师，或使用题材风格多选和搜索栏。
2. 输入昵称、账号、简介或题材相关关键词后点击“搜索”。
3. 打开画师主页，查看公开作品、橱窗、简介和合作评价；需要时切换主页身份视角查看企划方信息。
4. 想合作时使用主页“邀请”，或先选具体橱窗。邀请需要你已有可邀请的公开企划，见 PROJECT-06。

结果：了解画师的实际展示内容。评价、完成率等是历史参考，不等于当前接稿档期或统一报价；不要把某件橱窗价格当作该画师所有业务的价格。画师大厅和向导的推荐查询不是完全相同的筛选入口，向导依据见 GUIDE-03。

## BROWSE-04 浏览作品与查看大图

入口：顶部“作品” → `/works`。

1. 选择“最新”或“热门”，在作品分类、题材风格中缩小范围，也可以输入标题/说明关键词后按回车。
2. 点击作品图片，在弹出的作品详情中查看作品说明和作者信息。
3. 需要了解作者时使用详情中的作者主页入口；继续浏览时关闭详情。
4. 向下滚动加载更多作品。

结果：浏览公开作品。作品题材支持多选，但它的选项与企划专用题材不是同一套。隐藏、私密和已删除作品不会出现在广场。

## BROWSE-05 关注画师、取消关注

适用对象：登录用户。入口：已认证画师的公开主页。

1. 进入目标画师主页，点击“关注”。
2. 回到画师大厅的“关注”视图，查看关注的画师；工作台“画师收藏”快捷入口也用于访问该列表。
3. 在作品广场选择“关注画师的”，浏览这些画师公开的作品。
4. 想取消时回到主页，使用“已关注”按钮取消。

结果：建立或取消关注关系，不会自动发送邀请或下单。账号级屏蔽会限制关注；不能关注自己。没有独立的收藏中心页面。

## BROWSE-06 收藏作品、橱窗与查找收藏

适用对象：登录用户。入口：作品卡片/详情的心形按钮、橱窗详情“收藏橱窗”。

1. 找到他人的公开作品或上架橱窗，点击收藏按钮。
2. 作品可在广场“我收藏的”查看；橱窗可通过工作台“橱窗收藏”快捷入口查看。工作台还提供“作品收藏”快捷入口。
3. 再点已收藏按钮可取消，操作前确认目标标题，避免点错。

结果：收藏在两个工作台之间共用。收藏不是购买，也不保留库存；目标隐藏、下架或删除后可能不再显示在有效收藏列表中，这不代表原订单被删除。
