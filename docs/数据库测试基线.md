# 数据库测试基线

## 1. 用途

`scripts/database-baseline.ps1` 用于把本机 Artiv MySQL 数据库恢复到正式测试开始前的固定状态。

基线 SQL、校验文件以及每次还原前的自动备份保存在项目根目录 `.artiv-data/`。该目录已加入 `.gitignore`，不得提交，其中可能包含账号、消息、订单和其他测试数据。

本脚本只处理 MySQL 数据库，不删除或还原 `backend/uploads/`。测试期间不要手工删除仍可能被数据库引用的上传文件。

## 2. 当前基线

首次执行以下命令会保存当前数据库：

```powershell
cd G:\ProjectForGraduation\Artiv
powershell.exe -ExecutionPolicy Bypass -File .\scripts\database-baseline.ps1 -Action Capture
```

查看基线状态及完整性：

```powershell
powershell.exe -ExecutionPolicy Bypass -File .\scripts\database-baseline.ps1 -Action Status
```

如果确实需要用新的当前数据替换旧基线，必须显式执行：

```powershell
powershell.exe -ExecutionPolicy Bypass -File .\scripts\database-baseline.ps1 -Action Capture -ReplaceBaseline
```

替换前的旧基线会自动保存在同一目录，不会直接丢失。

## 3. 测试后还原

先停止后端，避免还原过程中仍有请求写入数据库，然后执行：

```powershell
cd G:\ProjectForGraduation\Artiv
powershell.exe -ExecutionPolicy Bypass -File .\scripts\database-baseline.ps1 -Action Restore -ConfirmRestore
```

安全规则：

- 不带 `-ConfirmRestore` 时拒绝覆盖数据库。
- 还原前会自动生成 `pre-restore-时间.sql`，保存测试结束时的数据。
- 还原前校验基线 SHA-256，损坏或被修改时拒绝执行。
- 默认只允许还原到 `localhost`、`127.0.0.1` 或 `::1`；远程数据库必须额外显式添加 `-AllowRemote`。
- 数据库目标、账号和密码从 `backend/src/main/resources/application.yml` 或其中引用的环境变量读取，密码不会写入脚本或命令参数。

## 4. 自定义位置

如需使用其他快照或配置文件，可以传入：

```powershell
powershell.exe -ExecutionPolicy Bypass -File .\scripts\database-baseline.ps1 `
  -Action Status `
  -SnapshotPath D:\backup\artiv-baseline.sql `
  -ConfigPath .\backend\src\main\resources\application-local.yml
```
