# 绘约（HuiYue）项目交接说明：企划详情分支版本

> 来源：`feature/project-detail` 隔离分支，最新文档提交 `25d257f`。

## 已实现

- 企划详情页：参考站的信息层级样式、发布者侧栏、预算/截止日期、参考图、描述、稿件要求。
- 企划发布：多参考图与结构化稿件要求。
- 应征：认证画师应征和撤销；企划作者查看应征画师资料与作品。
- 项目沟通：仅企划作者可以主动发起，画师仅可回复。
- 项目订单：仅保留“发送企划订单”的占位接口，未实现真实订单。

## 重要边界

- 约稿大厅没有改动，仍将第一张参考图作为封面。
- 发布者资料通过企划详情接口返回最小安全字段，不公开完整用户资料。
- 当前最终只能选定一名画师；后续可根据应征记录扩展多画师。

## 仍需测试

- 两账号在浏览器中的实时聊天。
- 企划作者点击私信与订单占位按钮。
- 干净数据库迁移脚本。
