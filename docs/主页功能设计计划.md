# 艺绘（Artiv）主页功能设计计划

> 状态：第一期已实现并完成自动化与浏览器联调
> 更新时间：2026-08-20
> 目标：在不重复建设工作台的前提下，为每个账号提供可公开访问的画师主页与企划方主页。

## 1. 设计边界

- 同一账号可拥有画师、企划方两种公开身份；右上角“切换身份”只切换当前主页视图，不改变账号权限。
- 本期设计真实接入：公开资料、公开作品、公开橱窗、已发布企划，以及画师视角的需求完成率、准时交稿率。
- 关注画师和主页邀请仍只预留入口；合作评价已于 2026-08-23 接入 F10 真实评分与评价列表，不展示虚构分数。
- 不做价目表、档期安排、在线状态、屏蔽/举报、资金管理和私密资料展示。

## 2. 路由与访问规则

建议统一公开路由：`/profiles/{userId}?role=painter|employer`。

- `role=painter`：画师视角主页；正常用户无论是否认证均可访问，认证状态通过徽标区分。账号不存在、已删除或被封禁时显示明确空态。
- `role=employer`：企划方主页；账号正常即可访问。
- 公开主页统一为只读展示，不再显示本人“编辑资料”入口；资料修改统一进入 `/settings`。查看他人画师主页时可保留“关注”“邀请”后续扩展位。
- 切换身份时只替换查询参数并保留用户 ID，避免产生两套重复页面和重复资料。

## 3. 画师主页

### 3.1 页面结构

1. 顶部横幅：默认品牌背景，后续可扩展自定义封面。
2. 身份摘要：头像、昵称、认证/未认证标签、个人简介、题材风格标签；存在有效评价时展示角色对应的真实平均分和评价数。
3. 业务指标：需求完成率、准时交稿率。无有效样本时显示“暂无”，不显示虚假 100%。
4. 二级菜单：`作品 / 橱窗 / 合作评价`。
5. 操作区：本人不显示编辑入口；他人为“邀请（预留）/ 关注（预留）”。

### 3.2 指标口径

- 需求完成率 = 画师已完成订单数 ÷（已完成 + 画师拒单后确认终止 + 画师责任取消）订单数。
- 准时交稿率 = 截稿日前完成的订单数 ÷ 有明确截稿日期的已完成订单数。
- 退款/售后仍未完成管理员责任判定前，不计入分母，避免错误归责。
- 接口应同时返回分子、分母和百分比，前端不能只接收孤立百分比。

### 3.3 作品标签页

- 仅展示公开、未删除作品；按 4 列布局，每批 20 件。
- 初次加载 20 件；观察哨兵距视口底部约 600px 时预取下一批。
- 同一批请求期间锁定加载；按作品 ID 去重；切换筛选或身份时递增请求版本，丢弃旧请求返回。
- 加载失败保留已显示内容并提供“重新加载”；连续空批或 `records.length < 20` 时终止。

### 3.4 橱窗标签页

- 复用橱窗大厅的公开卡片和详情路由，仅展示上架、未删除且库存大于 0 的橱窗。
- 不在主页复制下单逻辑；点击卡片进入既有橱窗详情后下单。

## 4. 企划方主页

### 4.1 页面结构

1. 顶部横幅与头像区。
2. 昵称、企划方简介；不显示画师认证标签或需求完成率。
3. 二级菜单：`发布企划 / 合作评价`。
4. 发布企划只展示公开招募中或已正常完成且允许公开的企划；下架、删除、定向邀请和草稿不公开。

### 4.2 企划列表

- 复用企划大厅卡片字段和详情路由，避免另建展示模型。
- 每批建议 12 项；滚动加载规则与作品一致。
- 已结束企划明确显示状态，不能继续应征。

## 5. 建议接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/v1/users/{id}/public-profile?role=painter|employer` | 公开身份摘要、简介、认证和指标 |
| GET | `/api/v1/users/{id}/works?page=1&size=20` | 画师公开作品动态加载 |
| GET | `/api/v1/users/{id}/stalls?page=1&size=20` | 画师公开橱窗 |
| GET | `/api/v1/users/{id}/projects?page=1&size=12` | 企划方公开企划 |
| POST | `/api/v1/users/{id}/follow` | 关注预留；本期不实现 |
| POST | `/api/v1/users/{id}/invitations` | 邀请预留；需后续确认与具体企划的绑定方式 |

公开 DTO 禁止返回用户名、余额、手机号、密码、私密订单、私聊、草稿和后台认证材料。

## 6. 组件复用建议

- `PublicProfileHeader`：横幅、头像、身份与按钮。
- `ProfileMetrics`：仅用于画师视角的完成率、准时率和样本说明。
- `ProfileTabs`：身份对应的二级菜单。
- `InfiniteCollection`：哨兵、并发锁、请求版本、去重、失败重试和结束态。
- 作品卡、橱窗卡、企划卡直接复用现有大厅组件；若当前页面仍为内联模板，先抽组件再建设主页。

## 7. 开发顺序

1. 明确公开 DTO、指标口径与隐私字段。
2. 实现公开资料和三个分页资源接口及单元测试。
3. 抽取大厅卡片和通用动态加载容器。
4. 实现画师主页及作品/橱窗标签页。
5. 实现企划方主页及发布企划标签页。
6. 添加身份切换、本人/他人权限差异与占位按钮。
7. 双身份、未认证、空数据、隐藏资源、移动端和滚动加载回归。

## 8. 验收标准

- 访问同一用户可在画师/企划方主页间切换，URL 可复制并直接打开。
- 页面不泄露余额、账号名、私密订单、定向企划或隐藏作品。
- 作品按 4×20 方案动态加载，重复触底不会重复数据或并发请求。
- 橱窗和企划点击进入既有详情，状态和权限与大厅一致。
- 画师指标无样本时显示“暂无”；企划方主页不展示需求完成率；合作评价使用 F10 真实接口，关注和主页邀请仍为预留状态。

## 9. 2026-08-18 实施结果

- 已启用统一公开路由 `/profiles/{userId}?role=painter|employer`，同一账号可在画师主页与企划方主页间切换。
- 已实现公开资料、公开作品、公开橱窗、公开企划四组接口；公开资料 DTO 在画师视角返回完成/准时统计的分子、分母和百分比，不返回用户名、余额、手机号等私密字段。
- 所有正常用户均可打开画师视角主页并查看自己的公开作品；未认证用户显示“未认证”，认证用户显示“认证画师”。画师主页保留需求完成率和准时交稿率；企划方主页只展示简介及公开企划，不再展示需求完成率（`13b938e`）。
- 画师与企划方简介已拆分存储，公开主页只读；账号、企划方简介和画师资料统一从 `/settings` 维护（`c1a629c`）。
- 作品与橱窗每批 20 项，企划每批 12 项；滚动加载使用请求版本隔离、并发锁和 ID 去重，失败时可点击重试。
- 作品卡可查看大图，橱窗卡和企划卡进入既有详情；作品详情、画师大厅、企划详情和顶部账号菜单均已接入公开主页入口。
- 关注和主页邀请仍为明确占位，不伪造业务结果；合作评价已接入角色分离评分、分页列表和画师删除申诉。
- 最新验证：后端 69 项测试通过；前端生产构建通过；浏览器使用未认证且有 1 件公开作品的 `Demotest1` 验证画师主页、未认证徽标和作品正常显示，企划方主页无需求完成率，页面无横向溢出和控制台错误。
- 首屏固定五图保持纯展示；第 1、5 张人物图分别使用 `object-position: center 18%` 和 `center 24%` 调整裁切焦点，使人物面部在现有卡片尺寸内可见（`e08f0cc`）。素材来源和发布边界见项目根目录《素材与版权免责声明.md》；该声明不能替代实际授权。
