# 绘约（HuiYue）演示脚本

> 目标时长：15 分钟 ｜ 演示前准备：启动 MySQL80、后端（8080）、前端（5173）、导入演示数据

## 演示账号

| 角色 | 账号 | 密码 |
|------|------|------|
| 企划方 | `planner` | `123456` |
| 画师 | `artist` | `123456` |
| 管理员 | `admin` | `123456` |

---

## 第 1 段：项目介绍（2 分钟）

1. 打开项目首页，展示平台定位：美术约稿交易平台。
2. 口播核心业务闭环：发布需求 → 画师应征 → 选定下单 → 沟通修改 → 分阶段验收 → 互相评价。
3. 简要说明技术栈：Vue 3 + Spring Boot + MySQL，前后端分离。

## 第 2 段：注册与登录（2 分钟）

1. 打开注册页，演示画师账号注册（头像、昵称、角色）。
2. 使用 `artist` 登录，刷新页面确认登录态保持（JWT）。
3. 展示个人中心资料编辑。

## 第 3 段：发布企划与应征（3 分钟）

1. 切换企划方账号 `planner`，点击「发布企划」，填写标题、需求描述、预算、截止时间并上传参考图。
2. 发布成功后，在首页列表看到新企划。
3. 切换画师账号 `artist`，进入企划详情，提交应征（附作品与报价）。
4. 切回企划方，在应征列表看到画师应征记录。

## 第 4 段：下单与分阶段验收（4 分钟）

1. 企划方在应征列表中选定画师，创建订单。
2. 画师端看到「进行中」订单，上传初稿。
3. 企划方进入订单详情，验收初稿并填写修改意见（可多次沟通）。
4. 画师提交终稿，企划方确认验收，订单流转为「已完成」。
5. 双方互相评价，展示评价内容。

## 第 5 段：消息与实时通知（2 分钟）

1. 打开两个浏览器窗口（企划方 / 画师）。
2. 画师应征后，企划方页面不刷新即收到实时消息提醒（WebSocket）。
3. 展示消息中心列表与已读 / 未读状态。

## 第 6 段：管理后台（2 分钟）

1. 使用 `admin` 登录，进入管理后台。
2. 展示用户列表、封禁 / 解封操作。
3. 展示企划审核列表与上架 / 下架操作。
4. 展示平台统计（注册量、订单量、成交额图表）。

## 收尾（1 分钟）

1. 总结系统覆盖的业务闭环与亮点（实时消息、分阶段验收、权限控制）。
2. 结束语：感谢观看，欢迎提问。

---

## 应急预案

| 问题 | 处理 |
|------|------|
| 数据库连不上 | 检查 MySQL80 服务，确认 root 密码与 `application.yml` 一致 |
| 前端 403 / 404 | 确认后端已启动、代理配置正确、接口前缀为 `/api/v1` |
| WebSocket 连不上 | 检查 `/ws` 代理的 `ws: true` 配置与 token 参数 |
| 演示数据被改乱 | 重新执行 `backend/sql/init.sql` 恢复演示数据 |
| 网络 / 设备故障 | 使用提前录制的录屏兜底 |
