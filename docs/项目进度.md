## 3. 已完成内容（有据可查）

### 3.1 数据库（阶段 1 主体）

- `huiyue` 库已创建，10 张表全部就绪：`user`、`work`、`stall`、`project`、`application`、`invitation`、`order_info`、`order_stage`、`message`、`review`
- 演示数据已导入：planner（企划方）、artist（画师，已认证 cert_status=2）、admin；密码均为 123456
- 字段命名与开发计划一致：`employer_id` / `painter_id` / `cert_status` / `mode` / `recruit_deadline` 等
- 初始化脚本：`backend/sql/init.sql`

### 3.2 后端（阶段 1 主体）

- 认证：注册（模拟注册，角色 1/2）、登录（JWT）、`/auth/me`；已实测通过
- 统一返回体 `{code, message, data}`、全局异常处理、错误码枚举
- JWT 拦截器（无 token / 伪造 token 均返回 401）
- 接口骨架（列表/详情/创建为主）：
  - `AuthController`：register / login / me
  - `ProjectController`：企划列表（公开招募过滤）
  - `WorkController`：作品列表 / 创建 / 删除
  - `StallController`：服务板列表 / 详情 / 创建 / 编辑 / 上下架
  - `InvitationController`：邀请列表 / 创建 / 接受拒绝
  - `OrderController`：订单列表 / 详情 / 创建
  - `ReviewController`：评价列表 / 提交评价
- 实体 9 个、Mapper 8 个，`mvn compile` 通过

### 3.3 前端（阶段 2 主体，需大幅优化修改）

- 首页：参照米画师样式重构（hero、特性区、作品展示、方案区、评价区、CTA、页脚），已实测渲染正常
- 登录 / 注册页：居中卡片 + 角色选择，已实测可用
- 全局：Element Plus 主题色（`#00a8e9`）、统一顶部导航 `AppHeader`（首页/工作台共用，含发布需求、消息铃铛、头像下拉、登录/注册按钮）
- 路由：公开页（/、/artists、/works、/projects、/stalls 等）＋ 三工作台（/dashboard、/painter、/admin）
- API 封装：user / project / work / stall / invitation / review / order / message
- `npm run build` 通过

工作台（参照 MihuashiMerged 登录后站点）：

- 企划方工作台：欢迎卡 + 统计、我的企划（真实数据 + 分页）、发布企划 4 步向导、应征管理、订单管理、消息中心

> **剩余优化**：画师/企划详情页、站内信聊天页等仍为占位，待阶段 3/4 填充。

## 4. 未完成 / 待办

### 4.1 阶段 2 收尾（建议先做）

- 工作台页面目前均为占位（「开发中」提示）：
  - 企划方：/dashboard（首页、我的企划、发布企划、应征管理）
  - 画师：/painter（资料认证、作品集、服务板、应征、邀请、订单）
  - 管理：/admin（用户管理、企划审核、统计）

### 4.2 阶段 3（核心闭环，工作量最大）

- 企划发布 / 修改 / 下架（后端目前只有 GET 列表）
- 画师应征（提交 / 查看 / 撤销）
- 企划方选定画师 → 创建订单
- 分阶段验收（order_stage 提交与确认）
- 订单状态机（待接单 → 进行中 → 待验收 → 已完成 / 已取消 / 争议中）
- 模拟托管结算（阶段验收通过即结算）
- 业务约束：未认证画师不能接稿 / 开服务板；定向企划仅被邀画师可见；招募期自动关闭

### 4.3 其他待办

- 后端缺少：`UserController`（资料编辑、头像）、`AdminController`（用户管理 / 企划审核 / 统计）、`UploadController`（文件上传）
- WebSocket 仍是骨架（未解析 token、未落库推送）
- 画师/企划详情页、站内信聊天页为占位；个人中心待接入资料编辑
- 评价闭环（订单完成后方可互评）未实现
