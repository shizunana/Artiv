- 初始化脚本：`backend/sql/init.sql`

### 3.2 后端（阶段 1 主体）

- 认证：注册（模拟注册，角色 1/2）、登录（JWT）、`/auth/me`；已实测通过
- 统一返回体 `{code, message, data}`、全局异常处理、错误码枚举
- JWT 拦截器（无 token / 伪造 token 均返回 401）
- 接口骨架（列表/详情/创建为主）：
  - `AuthController`：register / login / me
  - `ProjectController`：企划列表（公开招募过滤）
  - `WorkController`：作品列表 / 创建 / 删除
  - `StallController`：服务板列表 / 详情 / 创建 / 编辑 / 上下架
  - `InvitationController`：邀请列表 / 创建 / 接受拒绝
  - `OrderController`：订单列表 / 详情 / 创建
  - `ReviewController`：评价列表 / 提交评价
- 当前实体与 Mapper 各 15 个；后端完整回归最近为 67 项通过

### 3.3 前端（阶段 2–5 主体）

- 首页：已重构为真实内容门户，展示公开作品、招募企划、橱窗和认证画师；不展示虚构指标、静态评价或平台能力宣传
- 登录 / 注册页：居中卡片 + 角色选择，已实测可用
- 全局：Element Plus 主题色（`#00a8e9`）、统一顶部导航 `AppHeader`（首页/工作台共用，含发布需求、消息铃铛、头像下拉、登录/注册按钮）
- 路由：公开页（/、/artists、/works、/projects、/stalls 等）＋ 三工作台（/dashboard、/painter、/admin）
- API 封装：user / project / work / stall / invitation / review / order / message
- `npm run build` 通过

工作台（参照 MihuashiMerged 登录后站点）：

- 企划方工作台：欢迎卡 + 统计、我的企划（真实数据 + 分页）、发布企划 4 步向导、应征管理、订单管理、消息中心
