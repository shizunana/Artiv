# 艺绘（Artiv）优化方案构想

> 用途：记录尚未进入正式开发范围、可在后续对比评估的产品和界面方案。本文件仅作为备选构想，不代表已经排期或实现。

## 1. 消息中心独立于工作台

### 当前方案

- 消息中心继续位于画师、企划方工作台内部。
- 两个工作台复用同一套会话数据和消息能力，仅入口路由不同。
- 左侧保留工作台导航，消息页内部维持“会话列表 + 聊天区域”的两栏结构。

### 备选方案

- 将消息中心调整为与工作台并列的独立一级页面，由顶栏铃铛、企划应征、橱窗和订单页面统一进入。
- 独立页面不展示画师或企划方工作台侧栏，避免同一会话因当前工作台身份产生视觉割裂。
- 消息权限仍按登录账号、会话参与关系和业务资源归属判断，不因脱离工作台而改变。
- 画师/企划方工作台的“消息中心”菜单可保留为统一入口，跳转至同一独立路由。

### 后续评估点

- 顶栏返回路径、面包屑或“返回工作台”入口如何表达。
- 移动端是否采用“会话列表页 → 单独聊天页”的双页面结构。
- 现有 `/dashboard/messages`、`/painter/messages` 是否兼容跳转到新的统一路由。
- 系统通知与私信是否继续放在同一页面的两个标签中。

### 当前结论

暂不实施独立路由。先保留现有空间结构，并统一右侧会话区域的视觉语言：普通私信使用左右气泡，平台事件使用居中的系统信息卡。现行视觉方案已由 `972a38f` 实现。
