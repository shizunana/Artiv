## P0 高优先级：企划创作阶段与企划管理改造

> 以下 5 项需求已于 2026-08-14 确认，**均尚未编码**。开发时必须同步数据库、后端接口、发布企划、企划详情、我的企划、订单阶段初始化和橱窗创建/编辑，不能只改页面文案。

- [ ] **发布企划增加“创作阶段”**：在发布企划向导的“需求详情”页、参考图下方增加创作阶段编辑器，复用橱窗的阶段编辑方式。默认 3 次提交：`初稿 → 修改 → 终稿`；允许增删、重命名和排序自定义阶段，但不再填写百分比。所有页面、接口和文档中的“交付流程”统一改称“创作阶段”（2026-08-14）。
- [ ] **修正企划订单多余交付阶段**：当前正式企划订单按 `初稿 → 修改 → 终稿 → 交付` 初始化，导致终稿确认后仍有一次“交付”。目标规则是终稿本身就是最终交付，默认仅 3 个阶段；最后一个阶段验收通过即完成订单、结算并开放高清原图。历史订单继续使用创建时快照，不做破坏性迁移（2026-08-14）。
- [ ] **企划详情增加统一“变更企划”功能**：仅企划发布者可见，入口位于左侧“返回企划列表”上方。支持上架/下架和删除。下架后从企划大厅隐藏并停止新应征、新发单，但不取消或修改既有订单；既有订单双方仍可进入下架企划详情。只有该企划从未产生任何订单时才允许删除；只要存在任意状态的关联订单（包括已完成/已取消）均禁止删除（2026-08-14）。
- [ ] **重构“个人中心—我的企划”**：参考画师方“我的橱窗”列表，显示 `封面 / 企划名 / 类型 / 预算 / 企划详情 / 状态 / 编辑`。列表“编辑”与企划详情“变更企划”必须调用同一组件和同一组接口，可在列表直接管理而不必先进入详情（2026-08-14）。
- [ ] **橱窗创作阶段去除百分比**：创建橱窗和修改橱窗的自定义创作阶段只保留阶段名称、顺序及增删，不再允许填写百分比。既有橱窗和既有订单保留历史阶段快照，避免影响已下单履约（2026-08-14）。
