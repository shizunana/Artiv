## 3. 已知环境注意事项

- MySQL80 服务为手动启动：重启电脑后需手动启动（建议设置自动启动）。
- npm 在 PowerShell 下需用 `npm.cmd`（执行策略限制）。
- 上传文件保存在 `backend/uploads/`（git 已忽略）。
