# 绘约（HuiYue）接口文档：企划详情分支版本

> 来源分支：`feature/project-detail`；供 Windows 主项目目录直接查看。

| 方法 | 路径 | 状态 | 说明 | 权限 |
| --- | --- | --- | --- | --- |
| GET | `/api/v1/projects/{id}` | 已实现 | 企划详情，包含安全 `employer` 摘要：`id/nickname/avatar/bio/tags` | 公开 / 受邀 |
| GET | `/api/v1/projects/{id}/applications` | 已实现 | 应征详情，返回 `application`、画师资料、最多 4 个作品 | 企划作者 |
| POST | `/api/v1/projects/{projectId}/conversations/{painterId}` | 已实现 | 企划作者为待处理/已选定应征画师主动发起或取得项目会话 | 企划作者 |
| POST | `/api/v1/projects/{id}/order-intents/{painterId}` | 占位 | 返回 `订单功能开发中`；不创建订单、不改变状态 | 企划作者 |
| POST | `/api/v1/projects/{id}/applications` | 已实现 | 已认证画师提交 `intro` 与正数 `quote` | 已认证画师 |
| DELETE | `/api/v1/applications/{id}` | 已实现 | 画师撤销自己的待处理应征 | 应征画师本人 |

## 发布企划的新增字段

```json
{
  "images": ["/uploads/a.png", "/uploads/b.png"],
  "requirements": {
    "size": "3000×4000 px",
    "colorMode": "RGB",
    "formats": ["PNG", "PSD"],
    "publishPermission": "仅作品集展示"
  }
}
```

`employer` 是企划接口专用安全摘要；详情页不调用 `/api/v1/users/{id}`。
