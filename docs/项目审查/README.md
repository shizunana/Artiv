# 项目审查文档索引

本目录集中保存 Artiv 的代码质量、安全边界、数据一致性与业务状态机审查报告。报告以发现问题和给出整改建议为主；除非另有说明，审查过程不直接修改业务实现。

| 文档 | 用途 |
| --- | --- |
| [综合代码审查报告.md](./综合代码审查报告.md) | 项目整体代码质量、构建、接口、安全、性能与工程化概览 |
| [权限与越权审计报告.md](./权限与越权审计报告.md) | 登录、管理员、资源归属、文件访问、WebSocket 与跨域边界专项审计 |
| [事务与幂等审计报告.md](./事务与幂等审计报告.md) | 资金、库存、订单、应征、邀请、黑名单、评价与消息一致性专项审计 |

## 风险等级

- **P1 高**：正式部署前应解决，可能造成隐私泄露、绕过授权、重复扣款或核心业务关系不一致。
- **P2 中**：建议在 RC 前解决，通常需要并发、部署条件或异常重试才能触发，但会扩大安全或可靠性风险。
- **P3 低**：工程健壮性与长期维护问题，可纳入质量收尾阶段。
