## 1. 通用约定

### 1.1 基础信息

- 基础路径：`/api/v1`
- 开发环境地址：`http://localhost:8080`
- 数据格式：JSON（`Content-Type: application/json`）
- 认证方式：登录后请求头携带 `Authorization: Bearer <token>`

### 1.2 统一返回结构

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {}
}
```

| code | 含义 |
|------|------|
| 200 | 成功 |
| 400 | 参数错误 |
| 401 | 未登录 / 登录过期 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

### 1.3 分页返回结构

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "total": 100,
    "current": 1,
    "size": 10,
    "records": []
  }
}
```

## 2. 认证模块 `/auth`（✅ 已实现）

### 2.1 注册（模拟注册）

`POST /api/v1/auth/register`

```json
{
  "username": "artist001",
  "password": "123456",
  "nickname": "阿绘",
  "role": 2
}
```

> `role`：1 企划方、2 画师、3 管理员（注册仅允许 1 / 2）。无手机验证码、无短信。

响应：`data` 为创建的用户信息（不含密码）。

### 2.2 登录

`POST /api/v1/auth/login`

```json
{
  "username": "artist001",
  "password": "123456"
}
```

响应：

```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9...",
    "user": { "id": 1, "username": "artist001", "nickname": "阿绘", "role": 2, "certStatus": 0 }
  }
}
```

### 2.3 获取当前用户

`GET /api/v1/auth/me`（需登录）

响应：`data` 为当前登录用户信息（含 `role`、`certStatus`、`bio`、`tags`）。

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| POST | `/api/v1/projects` | 发布企划（含合作方式 mode，所有登录用户可用） | 登录用户 |
| GET | `/api/v1/projects` | 约稿大厅（分页 / 关键词 / 状态筛选，仅公开招募） | 公开 |
| GET | `/api/v1/projects/mine` | 我的企划（企划方工作台） | 本人 |
| GET | `/api/v1/projects/{id}` | 企划详情（定向企划仅被邀画师可见） | 公开 / 受邀 |
| PUT | `/api/v1/projects/{id}` | 修改企划 ⏳ 待实现 | 作者 |
| DELETE | `/api/v1/projects/{id}` | 下架 / 关闭企划 ⏳ 待实现 | 作者 / 管理员 |

### 6.1 发布企划示例

```json
{
  "title": "国潮风节日海报插画",
  "description": "需要一张国潮风格的节日海报插画",
  "budget": 1500.00,
  "deadline": "2026-09-01",
  "tags": ["国潮", "插画"],
  "category": "头像",
  "subject": ["Q版", "日系"],
  "images": ["/uploads/xxx.png"],
  "mode": 0
}
```

> `mode`：0 公开招募（全员可见）、1 定向邀请（仅被邀画师可见）。`recruit_deadline` 默认发布后 10 日。
> `category`：类型（同橱窗分类：头像 / 立绘 / 服设 等 10 项）；`subject`：题材风格（35 个选项，可多选）。

列表筛选参数：`category`（类型精确匹配）、`subject`（题材模糊匹配）。

### 6.2 企划状态

`TINYINT`：0 招募中、1 已选定、2 进行中、3 已完成、4 已关闭。

## 11. 消息模块 `/messages` 与 WebSocket（🚧 REST 已实现，WebSocket 为骨架）

### 11.1 REST 接口

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| GET | `/api/v1/messages` | 我的消息列表 | 本人 |
| PUT | `/api/v1/messages/{id}/read` | 标记已读 | 本人 |
| PUT | `/api/v1/messages/read-all` | 全部已读 | 本人 |

### 11.2 WebSocket

- 连接地址：`ws://localhost:8080/ws?token=<token>`
- 推送格式：

```json
{
  "type": "NEW_MESSAGE",
  "data": {
    "id": 100,
    "fromId": 2,
    "content": "您有新的应征消息",
    "createdAt": "2026-08-11 10:00:00"
  }
}
```

事件类型：`NEW_MESSAGE`（新消息）、`ORDER_UPDATE`（订单变化）、`APPLICATION`（新应征）、`SYSTEM`（系统通知）。

### 11.3 F9 C2C 下单—沟通补充（隔离分支 `feature/f9-messaging`，未合并）

| 方法 | 路径 | 状态 | 说明 |
|------|------|------|------|
| POST | `/api/v1/messages/private` | ✅ | 发送普通、应征或橱窗交易会话文本；可携带 `projectId` 或 `orderId`，两者不能同时携带。 |
| GET | `/api/v1/messages/conversations` | ✅ | 查询当前用户的会话摘要，按对方与企划/订单上下文隔离。 |
| GET | `/api/v1/messages/conversation` | ✅ | 查询指定会话历史。 |
| GET | `/api/v1/messages/notifications` | ✅ | 查询系统通知。 |
| GET | `/api/v1/messages/unread-count` | ✅ | 当前用户未读总数。 |
| PUT | `/api/v1/messages/notifications/read-all` | ⚠️ | 仅将非私信通知标记已读；过滤逻辑与自动化构建已验证，尚未完成双端未读私信的人工隔离复验。 |
| POST | `/api/v1/stalls/{id}/purchase` | ✅ | 跳过支付，创建只用于沟通关联的最小订单、双方系统通知及交易会话。 |
| PUT | `/api/v1/applications/{id}/select` | ✅ | 选定应征画师，向画师发送通知并创建项目沟通会话。 |

- 橱窗下单不会扣减库存，也不代表付款、接单或履约开始；支付及完整订单流转不属于本轮范围。
- `GET /api/v1/orders/{id}` 已限制为订单企划方或画师可读；非参与者访问实际测试订单已返回 `2003`。
- 项目沟通仅允许企划方和**已选定**的应征画师进入。
- 正式订单聊天 `POST/GET /api/v1/orders/{id}/messages` 仍未实现；橱窗沟通统一使用私信接口并传 `orderId`。

## 13. 文件上传（✅ 已实现）

`POST /api/v1/upload`

- 请求：`multipart/form-data`，字段名 `file`
- 响应：`data` 为可访问的文件相对路径（如 `/uploads/xxx.png`）
- 限制：单文件 ≤ 5MB，允许 `png/jpg/jpeg/gif/webp`

## 14. 通用错误码

| code | 场景 |
|------|------|
| 1001 | 用户名已存在 |
| 1002 | 用户名或密码错误 |
| 1003 | 登录过期，请重新登录 |
| 2001 | 参数校验失败 |
| 2002 | 资源不存在 |
| 2003 | 无权操作该资源 |
| 3001 | 状态流转不合法 |
| 3002 | 余额 / 预算不足 |
| 4001 | 上传文件类型或大小不合法 |
