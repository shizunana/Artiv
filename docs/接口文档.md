## 1. 通用约定

### 1.1 基础信息

- 基础路径：`/api/v1`
- 开发环境地址：`http://localhost:8080`
- 数据格式：JSON（`Content-Type: application/json`）
- 认证方式：登录后请求头携带 `Authorization: Bearer <token>`

### 1.2 统一返回结构

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {}
}
```

| code | 含义 |
|------|------|
| 200 | 成功 |
| 400 | 参数错误 |
| 401 | 未登录 / 登录过期 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

### 1.3 分页返回结构

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "total": 100,
    "current": 1,
    "size": 10,
    "records": []
  }
}
```

## 2. 认证模块 `/auth`（✅ 已实现）

### 2.1 注册（模拟注册）

`POST /api/v1/auth/register`

```json
{
  "username": "artist001",
  "password": "123456",
  "nickname": "阿绘",
  "role": 2
}
```

> `role`：1 企划方、2 画师、3 管理员（注册仅允许 1 / 2）。无手机验证码、无短信。

响应：`data` 为创建的用户信息（不含密码）。

### 2.2 登录

`POST /api/v1/auth/login`

```json
{
  "username": "artist001",
  "password": "123456"
}
```

响应：

```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9...",
    "user": { "id": 1, "username": "artist001", "nickname": "阿绘", "role": 2, "certStatus": 0 }
  }
}
```

### 2.3 获取当前用户

`GET /api/v1/auth/me`（需登录）

响应：`data` 为当前登录用户信息（含 `role`、`certStatus`、`bio`、`tags`）。

| PUT | `/api/v1/projects/{id}` | 修改企划 ⏳ 待实现 | 作者 |
| DELETE | `/api/v1/projects/{id}` | 下架 / 关闭企划 ⏳ 待实现 | 作者 / 管理员 |

### 6.1 发布企划示例

```json
{
  "title": "国潮风节日海报插画",
  "description": "需要一张国潮风格的节日海报插画",
  "budget": 1500.00,
  "deadline": "2026-09-01",
  "tags": ["国潮", "插画"],
  "category": "头像",
  "subject": ["Q版", "日系"],
  "images": ["/uploads/xxx.png"],
  "requirements": {
    "size": "3000×4000 px",
    "colorMode": "RGB",
    "formats": ["PNG", "PSD"],
    "publishPermission": "仅作品集展示"
  },
  "mode": 0
}
```

> `mode`：0 公开招募（全员可见）、1 定向邀请（仅被邀画师可见）。`recruit_deadline` 默认发布后 10 日。
> `category`：类型（同橱窗分类：头像 / 立绘 / 服设 等 10 项）；`subject`：题材风格（35 个选项，可多选）。

列表筛选参数：`category`（类型精确匹配）、`subject`（题材模糊匹配）。

### 6.2 企划状态

`TINYINT`：0 招募中、1 已选定、2 进行中、3 已完成、4 已关闭。

### 6.3 企划详情补充（2026-08-12，project-detail）

`GET /api/v1/projects/{id}` 已用于公开企划详情页。响应中 `employer` 是发布者安全摘要，不要求前端再请求 `/api/v1/users/{id}`，也不会返回用户名、密码、角色、认证状态、账号状态等敏感/内部字段。

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "id": 7,
    "title": "角色立绘约稿",
    "images": "[\"/uploads/a.png\",\"/uploads/b.png\"]",
    "requirements": "{\"size\":\"3000×4000 px\",\"colorMode\":\"RGB\",\"formats\":[\"PNG\",\"PSD\"],\"publishPermission\":\"仅作品集展示\"}",
    "employer": {
      "id": 12,
      "nickname": "Public publisher",
      "avatar": "https://example.com/avatar.png",
      "bio": "Illustration studio",
      "tags": "fantasy,game"
    }
  }
}
```

前端约定：`images` 的第一张仅作为约稿大厅卡片封面；详情页展示完整有序参考图。详情页实现范围包括公共信息、参考图、结构化需求、发布者摘要、应征与作者侧应征管理入口；不包含参考站的交易担保、完整评价区、推荐画师、相似企划、举报/收藏/分享等扩展区块。

### 6.4 项目会话与下单意图接口（2026-08-12，project-detail）

| 方法 | 路径 | 状态 | 说明 | 权限 |
| --- | --- | --- | --- | --- |
| POST | `/api/v1/projects/{projectId}/conversations/{painterId}` | ✅ | 企划作者为待处理或已选定应征画师发起/取得项目会话；已存在时返回已有首条会话消息。画师不能调用此接口发起会话。 | 企划作者 |

## 7. 应征模块 `/applications`（✅ 已实现）

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| POST | `/api/v1/projects/{id}/applications` | 画师应征（`intro` + 正数 `quote` + 可选作品链接） | 已认证画师 |
| GET | `/api/v1/projects/{id}/applications` | 查看企划应征列表（含画师基础资料和最多 4 个作品） | 企划作者 |
| GET | `/api/v1/applications/mine` | 我的应征（画师工作台） | 本人 |
| DELETE | `/api/v1/applications/{id}` | 撤销应征 | 本人 |

### 7.1 应征示例

```json
{
  "intro": "擅长国潮插画，可提供初稿预览",
  "workLink": "/works/1",
  "quote": 1200.00
}
```

应征状态：0 待处理、1 已通过、2 已拒绝、3 已撤销。

`GET /api/v1/projects/{id}/applications` 响应记录结构为 `ApplicationDetail`：`application`（应征记录）、`painter`（画师基础资料）、`works`（该画师最多 4 个作品）。该接口仅企划作者可访问。

撤销规则：`DELETE /api/v1/applications/{id}` 仅应征画师本人可调用，且当前仅待处理应征可撤销。

沟通规则：应征本身不会自动创建聊天；企划作者可通过 `/projects/{projectId}/conversations/{painterId}` 发起，画师不能主动发起，只能在已有会话内回复。

## 11. 消息模块 `/messages` 与 WebSocket（🚧 REST 已实现，WebSocket 为骨架）

### 11.1 REST 接口

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| GET | `/api/v1/messages` | 我的消息列表 | 本人 |
| PUT | `/api/v1/messages/{id}/read` | 标记已读 | 本人 |
| PUT | `/api/v1/messages/read-all` | 全部已读 | 本人 |

### 11.2 WebSocket

- 连接地址：`ws://localhost:8080/ws?token=<token>`
- 推送格式：

```json
{
  "type": "NEW_MESSAGE",
  "data": {
    "id": 100,
    "fromId": 2,
    "content": "您有新的应征消息",
    "createdAt": "2026-08-11 10:00:00"
  }
}
```

事件类型：`NEW_MESSAGE`（新消息）、`ORDER_UPDATE`（订单变化）、`APPLICATION`（新应征）、`SYSTEM`（系统通知）。

### 11.3 C2C 沟通前置接口（2026-08-12）

> 状态标记：✅ 已实现且本轮已实际联调；⚠️ 已实现但本轮未逐项人工联调；⏳ 不在本轮范围。

| POST | `/api/v1/messages/private` | ✅ | 发送文字消息。请求体新增可选 `orderId`；只能在本人参与的订单会话内使用，且不能与 `projectId` 同时传入。 |
| POST | `/api/v1/stalls/{id}/purchase` | ✅ | 无支付的橱窗下单：创建最小关联订单、买家/画师系统通知、首条交易会话消息。本轮不扣库存、不支付、不接单、不进入履约。 |
| PUT | `/api/v1/applications/{id}/select` | ✅ | 企划所属者选定待处理应征；将应征设为已通过并通知画师。不创建正式订单，也不自动创建项目沟通会话。 |
| POST | `/api/v1/projects/{projectId}/conversations/{painterId}` | ✅ | 企划作者为待处理/已选定应征画师发起或取得项目会话；画师不能主动发起。 |
| POST | `/api/v1/projects/{id}/order-intents/{painterId}` | ✅ 占位 | 返回 `订单功能开发中`；不创建订单、不改变状态。 |
| POST / GET | `/api/v1/orders/{id}/messages` | ⏳ | 正式订单内聊天接口未实现；当前橱窗沟通使用 `/messages/private` 加 `orderId`。 |
| PUT | `/api/v1/orders/{id}/status` | ⏳ | 接单、拒单、取消和完整状态流转不属于本轮。 |

#### 橱窗下单响应示例

`POST /api/v1/stalls/5/purchase`

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "id": 9,
    "stallId": 5,
    "employerId": 1,
    "painterId": 2,
    "amount": 120.00,
    "status": 0
  }
}
```

> `status=0` 在现有表结构中保留为“待接单”，但本轮不提供接单/拒单操作；它只表示创建了沟通关联记录，不能作为已支付、已接单或已开始履约的依据。

> `GET /api/v1/orders/{id}` 已增加订单参与者校验：只有 `employerId` 或 `painterId` 可读取；本轮已实际验证非参与者返回 403。

## 13. 文件上传（✅ 已实现）

`POST /api/v1/upload`

- 响应：`data` 为可访问的文件相对路径（如 `/uploads/xxx.png`）

## 14. 通用错误码

| code | 场景 |
|------|------|
| 1001 | 用户名已存在 |
| 1002 | 用户名或密码错误 |
| 1003 | 登录过期，请重新登录 |
| 2001 | 参数校验失败 |
| 2002 | 资源不存在 |
| 2003 | 无权操作该资源 |
| 3001 | 状态流转不合法 |
| 3002 | 余额 / 预算不足 |
| 4001 | 上传文件类型或大小不合法 |
