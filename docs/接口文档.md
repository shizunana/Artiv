# 绘约（HuiYue）接口文档

> 版本：v1.0 ｜ 更新时间：2026-08-11

## 1. 通用约定

### 1.1 基础信息

- 基础路径：`/api/v1`
- 开发环境地址：`http://localhost:8080`
- 数据格式：JSON（`Content-Type: application/json`）
- 认证方式：登录后请求头携带 `Authorization: Bearer <token>`

### 1.2 统一返回结构

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {}
}
```

| code | 含义 |
|------|------|
| 200 | 成功 |
| 400 | 参数错误 |
| 401 | 未登录 / 登录过期 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

### 1.3 分页返回结构

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "total": 100,
    "page": 1,
    "size": 10,
    "records": []
  }
}
```

## 2. 认证模块 `/auth`

### 2.1 注册

`POST /api/v1/auth/register`

请求体：

```json
{
  "username": "artist001",
  "password": "123456",
  "nickname": "阿绘",
  "role": 2
}
```

> `role`：1 企划方、2 画师、3 管理员

响应：`data` 为创建的用户信息（不含密码）。

### 2.2 登录

`POST /api/v1/auth/login`

```json
{
  "username": "artist001",
  "password": "123456"
}
```

响应：

```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9...",
    "user": { "id": 1, "username": "artist001", "nickname": "阿绘", "role": 2 }
  }
}
```

### 2.3 获取当前用户

`GET /api/v1/auth/me`

响应：`data` 为当前登录用户信息。

## 3. 用户模块 `/users`

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| PUT | `/api/v1/users/{id}` | 修改个人资料 | 本人 |

## 4. 企划模块 `/projects`

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| POST | `/api/v1/projects` | 发布企划 | 企划方 |
| GET | `/api/v1/projects` | 企划列表（支持分页 / 搜索 / 筛选） | 公开 |
| GET | `/api/v1/projects/{id}` | 企划详情 | 公开 |
| PUT | `/api/v1/projects/{id}` | 修改企划 | 作者 |
| DELETE | `/api/v1/projects/{id}` | 下架企划 | 作者 / 管理员 |
| POST | `/api/v1/projects/{id}/applications` | 画师应征 | 画师 |
| GET | `/api/v1/projects/{id}/applications` | 查看应征列表 | 作者 |

### 4.1 发布企划示例

`POST /api/v1/projects`

```json
{
  "title": "国潮风插画约稿",
  "description": "需要一张节日主题插画，用于海报宣传",
  "budget": 1500,
  "deadline": "2026-09-01",
  "tags": ["国潮", "插画"],
  "images": ["/uploads/xxx.png"]
}
```

## 5. 订单模块 `/orders`

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| POST | `/api/v1/orders` | 选定画师并创建订单 | 企划方 |
| GET | `/api/v1/orders` | 我的订单列表 | 本人 |
| GET | `/api/v1/orders/{id}` | 订单详情 | 双方 |
| PUT | `/api/v1/orders/{id}/stage` | 提交阶段验收结果 | 双方按阶段 |
| PUT | `/api/v1/orders/{id}/status` | 状态流转（取消 / 完成） | 双方 |
| POST | `/api/v1/orders/{id}/messages` | 订单内沟通消息 | 双方 |

### 5.1 订单状态

`TINYINT`：0 待接单、1 进行中、2 待验收、3 已完成、4 已取消、5 争议中。

### 5.2 创建订单示例

`POST /api/v1/orders`

```json
{
  "projectId": 1,
  "artistId": 2,
  "amount": 1500
}
```

## 6. 消息模块 `/messages` 与 WebSocket

### 6.1 REST 接口

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| GET | `/api/v1/messages` | 我的消息列表 | 本人 |
| PUT | `/api/v1/messages/{id}/read` | 标记已读 | 本人 |
| PUT | `/api/v1/messages/read-all` | 全部已读 | 本人 |

### 6.2 WebSocket

- 连接地址：`ws://localhost:8080/ws?token=<token>`
- 服务端推送消息格式：

```json
{
  "type": "NEW_MESSAGE",
  "data": {
    "id": 100,
    "fromUserId": 2,
    "content": "您有新的应征消息",
    "createdAt": "2026-08-11 10:00:00"
  }
}
```

事件类型：`NEW_MESSAGE`（新消息）、`ORDER_UPDATE`（订单状态变化）、`APPLICATION`（新应征）、`SYSTEM`（系统通知）。

## 8. 文件上传

`POST /api/v1/upload`

- 请求：`multipart/form-data`，字段名 `file`
- 响应：`data` 为可访问的文件相对路径（如 `/uploads/xxx.png`）
- 限制：单文件 ≤ 5MB，允许 `png/jpg/jpeg/gif/webp`

## 9. 通用错误码

| code | 场景 |
|------|------|
| 1001 | 用户名已存在 |
| 1002 | 用户名或密码错误 |
| 1003 | 登录过期，请重新登录 |
| 2001 | 参数校验失败 |
| 2002 | 资源不存在 |
| 2003 | 无权操作该资源 |
| 3001 | 状态流转不合法 |
| 3002 | 余额 / 预算不足 |
| 4001 | 上传文件类型或大小不合法 |
