# 艺绘（Artiv）

艺绘是一个面向企划方与自由画师的美术约稿交易平台（毕业设计项目），基于 **Vue 3 + Spring Boot + MySQL** 前后端分离开发。

完整业务闭环（详见[订单流转流程](docs/订单流转流程.md)）：

**发布需求 / 浏览固定价橱窗 → 应征或直接下单 → 双方沟通 → 画师接单 → 按创作阶段验收（水印保护）→ 模拟托管结算 → 互相评价**

## 技术栈

- 前端：Vue 3.5、Vite 5、Vue Router 4、Pinia 2、Axios、Element Plus 2.8
- 后端：Spring Boot 3.3、MyBatis-Plus 3.5.7、MySQL 8、JWT、WebSocket
- 数据库：MySQL 8（utf8mb4 / InnoDB）

## 启动方式

### 1. 数据库

1. 启动本地 MySQL 服务。
2. 执行 [`backend/sql/init.sql`](backend/sql/init.sql) 完成建库、建表并导入演示数据。
3. 按需修改 [`backend/src/main/resources/application.yml`](backend/src/main/resources/application.yml) 中的数据库连接信息。

### 2. 后端（Spring Boot）

```bash
cd backend
mvn spring-boot:run
```

后端默认端口：`8080`。

### 3. 前端（Vue 3 + Vite）

```bash
cd frontend
npm install
npm run dev
```

前端默认地址：`http://localhost:5173`，开发环境通过 Vite 代理将 `/api`、`/ws` 转发到后端。
